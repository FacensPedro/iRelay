## What's Changed
- iRelay connects to iDeck over the local network (Wi-Fi or Ethernet) instead of a USB cable. Apple's device service is no longer needed.
- Pair once: find the iPad on the network (or type its address) and enter the pairing code shown in iDeck > Settings > iRelay. Requires iDeck 1.0.15 or later.
- Nothing listens on the PC, so Windows Firewall needs no rule.
- Updated the Windows installer and in-app update package to version 3.5.19.
